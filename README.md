# 🧠 Prompt Engineering Framework

Each portfolio follows a progressive approach:

```text
Basic
  ↓
Broad + Example
  ↓
Role + Context
  ↓
Role + Context + Task
  ↓
Role + Context + Task + Constraints
  ↓
Role + Context + Task + Constraints + Format
  ↓
RCTCF + Evidence
```

### RCTCF

**R — Role**
Who should the AI act as?

**C — Context**
What background does the AI need?

**T — Task**
What exactly should it accomplish?

**C — Constraints**
What rules, limitations, or requirements should it follow?

**F — Format**
How should the output be presented?

**Evidence**
What data, assumptions, calculations, or sources should support the answer?

# 📊 Portfolio Methodology

Each business case follows a consistent structure:

### 01 — Problem

Define the business problem.

### 02 — Objective

Identify what the AI needs to accomplish.

### 03 — Prompt Development

Build the prompt progressively.

### 04 — Output

Generate the AI response.

### 05 — Evaluation

Evaluate the response for:

* Accuracy
* Relevance
* Clarity
* Completeness
* Business usefulness
* Output consistency

### 06 — Improvement

Identify weaknesses and improve the prompt.

### 07 — Final Prompt

Create the optimized version.

### 08 — Key Learning

Document what changed and why.

# 🔬 Prompt Development Example

### Level 1 — Basic

```text
Analyze this company's financial performance.
```

### Level 2 — Broad + Example

```text
Analyze this company's financial performance.

For example, consider revenue growth, profitability,
and debt levels.
```

### Level 3 — Role + Context

```text
Act as a financial analyst.

Analyze the financial performance of a mid-sized
technology company using its financial statements.
```

### Level 4 — Constraints + Format

```text
Act as a financial analyst.

Analyze the financial performance of a mid-sized
technology company using the provided financial data.

Calculate key financial ratios and identify major trends.

Present the results in a table followed by a
300-word management summary.
```

### Level 5 — Advanced

```text
Act as a senior financial analyst advising company management.

Context:
The company is a mid-sized technology business evaluating
its financial performance over the last three years.

Task:
Analyze revenue growth, profitability, liquidity,
leverage, and operational efficiency.

Constraints:
- Use only the provided financial data.
- Show calculations for major ratios.
- Clearly identify assumptions.
- Do not invent missing information.
- Distinguish facts from interpretations.

Format:
1. Executive Summary
2. Financial Metrics Table
3. Ratio Analysis
4. Key Trends
5. Business Implications
6. Areas Requiring Attention
7. Management Takeaways

Evidence:
Reference the specific figures used in each calculation.
```

# 📈 Prompt Evaluation Framework

Prompts are evaluated across multiple dimensions:

| Metric             | Question                                         |
| ------------------ | ------------------------------------------------ |
| **Clarity**        | Is the instruction easy to understand?           |
| **Context**        | Does the AI have enough background?              |
| **Specificity**    | Is the task clearly defined?                     |
| **Constraints**    | Are limitations specified?                       |
| **Format**         | Is the desired output structure clear?           |
| **Accuracy**       | Is the response factually reliable?              |
| **Evidence**       | Are claims supported where required?             |
| **Business Value** | Can the output actually support a business task? |
